## 🛠️ Personalizações Rápidas

### Alterar Cores
Edite em `style.css`:
```css
/* Mudar cor primária */
:root {
    --green-primary: #2ecc71;
    --green-dark: #27ae60;
}
```

### Adicionar Novas Seções
No `index.html`, copie a estrutura de uma seção existente:
```html
<section id="nova-secao" class="content-section">
    <div class="container">
        <h2>Título da Seção</h2>
        <!-- Conteúdo aqui -->
    </div>
</section>
```

### Customizar Mensagens
Edite o arquivo `dados.json` para gerenciar conteúdo dinamicamente.

## 🌐 Opções de Hospedagem

1. **GitHub Pages** (Gratuito)
   - Upload dos arquivos
   - Ativa automaticamente

2. **Netlify** (Gratuito + Pago)
   - Drag and drop
   - CI/CD automático

3. **Vercel** (Gratuito + Pago)
   - Otimizado para performance
   - Deploy automático

4. **Servidor Próprio**
   - Controle total
   - Melhor performance
