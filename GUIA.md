# 🌱 Agrinho 2026 - Segurança Alimentar e Produção Sustentável

Um site moderno e responsivo dedicado à promoção de segurança alimentar e práticas de produção sustentável.

## 📋 Conteúdo do Projeto

### Arquivos principais:
- **index.html** - Página principal com toda a estrutura do site
- **style.css** - Estilos responsivos e design moderno
- **script.js** - Funcionalidades interativas e animações

## 🎯 Seções do Site

### 1. **Navegação**
- Menu sticky com links rápidos para as principais seções
- Design responsivo que se adapta a dispositivos móveis

### 2. **Hero Section**
- Seção impactante com chamada à ação
- Gradiente verde representando sustentabilidade

### 3. **Segurança Alimentar**
- 4 cards explicando aspectos-chave:
  - Rastreabilidade
  - Qualidade do Solo
  - Água Limpa
  - Certificações

### 4. **Produção Sustentável**
- 4 pilares principais:
  - Redução de Químicos
  - Biodiversidade
  - Energia Renovável
  - Economia Circular

### 5. **Práticas Recomendadas**
- 6 práticas essenciais numeradas:
  1. Planejamento Agrícola
  2. Manejo de Solo
  3. Controle Integrado
  4. Monitoramento
  5. Treinamento
  6. Documentação

### 6. **Estatísticas**
- Contadores animados mostrando impacto global
- Atualiza automaticamente quando a seção fica visível

### 7. **FAQ (Perguntas Frequentes)**
- 4 perguntas com accordion interativo
- Expande/colapsa suavemente com animações

### 8. **Contato**
- Formulário funcional com validação
- Mensagem de sucesso ao enviar

### 9. **Footer**
- Navegação rápida
- Links de redes sociais
- Informações da empresa

## 🚀 Como Usar

1. **Abrir o site:**
   - Abra `index.html` em um navegador web

2. **Personalizar conteúdo:**
   - Edite o HTML para adicionar mais seções
   - Modifique o CSS em `style.css`
   - Estenda funcionalidades em `script.js`

3. **Adicionar imagens:**
   - Crie uma pasta `assets` ou `images`
   - Substitua URLs de placeholder por suas imagens

4. **Deploy:**
   - Copie os arquivos para um servidor web
   - Ou use um serviço de hospedagem estática (GitHub Pages, Netlify, Vercel)
